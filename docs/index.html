01Launch the full tool (Windows)

Building USB sticks and flashing need direct access to your PC, which a web page can't have. Paste this into PowerShell. It fetches the latest release from GitHub, verifies its SHA256, and starts the wizard.

irm https://lance6x5.github.io/Lazarus7/run.ps1 | iex

Want to look around first? Dry run: nothing is erased or flashed.

& ([scriptblock]::Create((irm https://lance6x5.github.io/Lazarus7/run.ps1))) -DryRun

Prefer not to pipe scripts from the web? Download the ZIP, read run.ps1, or clone the repo and double-click Lazarus7.cmd.

03Identify an Android tablet

For Android HP Slate 7 tablets only. Plug the tablet in with a data cable, then scan. Needs Chrome or Edge (WebUSB). Detection only: nothing is sent to the device.

An HP Stream 7 never shows up on a PC (its port is charge + OTG host only), so no result is normal for it. For Android Slates, try the key combos below while plugging in.

04First aid for the Stream 7

No tools needed. Try these before anything else.

Dead battery (most common "brick")
2 A wall charger, short cable, 4+ hours. A drained Bay Trail tablet shows nothing for the first hour.
Hard reset
Hold Power 15-30 s, release, then hold Power 5 s.
Startup menu
Tablet off: hold Vol-, press Power until the HP logo, release Power.
F2 diagnostics · F9 boot USB · F10 BIOS · F11 Windows recovery
F11 → Troubleshoot
Refresh your PC keeps your files. Reset your PC erases everything and restores factory Windows 8.1.
WIMBoot: don't delete the recovery partition
C: holds only ~4 GB. The rest of Windows 8.1 lives compressed in the ~5 GB recovery partition, so deleting it breaks Windows. Back it up first: Windows' Recovery Drive tool with "Copy the recovery partition" ticked, on its own 8 GB+ stick.
Can my PC flash it over a USB cable?
No. Its micro-USB port is charge + OTG host only, so the tablet never shows up on a PC. The PC builds a USB stick, and the tablet boots it with Vol- + Power → F9.
Where do I get recovery media?
Best: your own recovery drive, saved and verified on your PC with Lazarus7. Then HP Support. HP's Cloud Recovery Tool doesn't cover the Stream 7 or Windows 8.x.
Shopping list for USB work
micro-USB OTG adapter, a powered USB hub, USB keyboard (+ mouse: touch doesn't work in Windows Setup), two 8 GB+ USB sticks.
Android Slate 7 instead?
Recovery: Power + Vol+. Rockchip loader: hold Vol+ while plugging in USB. All combos by model.

05Operating systems for the Stream 7

Its Atom Z3735G is 64-bit, but the firmware is 32-bit UEFI only: install media must contain EFI\BOOT\BOOTIA32.EFI. Lazarus7 checks this for you.

OSVerdictNotes
Windows 8.1 with Bing (stock)Restore onlyHP recovery media brings back the factory WIMBoot image with all drivers. Out of support since Jan 2023: fine offline, risky online.
Debian 12 i386 (desktop)RecommendedLazarus7's default. Download is SHA256-verified, with tablet fixes applied after install. Security support to mid-2028.
Debian 12 + Kodi (media center)Best media optionBoots straight into Kodi 20, in landscape with working touch. VA-API hardware decode for H.264, MPEG-2 and VC-1 (no HEVC/VP9 hardware on this chip). One script after install.
Debian 13 amd64Not out of the boxNo i386 installer, and the amd64 netinst has only BOOTX64.EFI.
Lubuntu / XubuntuWith surgeryAdd GRUB ia32 by hand.
Alpine / ArchDIYgrub-install --target=i386-efi. Light on 1 GB RAM.
Android-x86 9.0-r2 (32-bit)ExperimentalIts ISO has bootia32.efi (checked), so it boots. Lazarus7 verifies the download with two published checksums. Touch, Wi-Fi and sound are unconfirmed on a Stream 7, so try Live mode first. Android 9 gets no security updates.
LibreELEC, Bliss OS, PrimeOSNoLibreELEC has no official 32-bit-UEFI support. Bliss OS and PrimeOS are 64-bit, and same-class Z3735F tablets report boot freezes. For Kodi, use Debian + Kodi.
Windows 10 x86Works, unsupportedOut of support since Oct 2025. May not activate with the 8.1 firmware key: Microsoft stopped honoring 8.x keys in 2023. Needs HP's 5701 drivers. Slow on 1 GB RAM.
Windows 11, ChromeOS Flex, Fedora, BatoceraNoNo 32-bit UEFI support.

Official downloads and support

Official sources only. Lazarus7 doesn't host or link to copies of HP or Microsoft recovery images: they can't be redistributed, and unofficial copies can't be verified.

HP Support
Ask for Stream 7 recovery media with your serial and product number (Stream7-Check saves both). BIOS password unlock codes come from here too.
HP Stream 7 Tablet 5701: drivers and software
Needed after a Windows 10 install: chipset/Driver Pack first, then Goodix touch, Realtek audio, Bluetooth, Kionix sensor.
Microsoft: Windows 10 download
Use the Media Creation Tool, choose 32-bit (x86) and ISO, then build the stick with Lazarus7. The Windows 8.1 download page is gone.
Debian 12 i386 images
Lazarus7 fetches and verifies these itself.
